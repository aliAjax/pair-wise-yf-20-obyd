# hxyfront-62008 烟花弹体装配工位台

单页（React + Vite + TypeScript，不加任何运行时依赖）的烟花弹体装配工位作业台，数据只保存在浏览器本地 localStorage。

## 业务规则

- 预置数据：四条工位、八只弹壳（口径 / 壳高 / 额定与剩余可灌药量）、四种引信（库存长度）。
- 装配：选择工位、弹壳、灌药克数、引信种类与引信长度，并确认静电接地。
- 以下任一情况**整批退回**，原工位和物料不动，也不写历史：
  1. 静电接地未确认；
  2. 灌药克数超过该弹壳剩余可灌药量；
  3. 引信长度不足壳高的一半。
- 装配成功后弹壳剩余可灌药量与引信库存相应扣减，弹体留在原工位。
- 返工：只能对在制工位返工，只能减药（不能加药），且必须重新确认静电接地；原装配记录保留，另追加一条返工记录，减少的药量回补到弹壳余量。
- 「恢复预置数据」可清空本地记录并回到初始台账。

## 文件划分

- `src/inventory.ts` —— 库存与规则：弹壳 / 引信台账、装配与返工校验、工位在制推算、localStorage 读写。
- `src/stations.tsx` —— 工位图：四条工位定义与在制状态卡片。
- `src/App.tsx` —— 页面：作业表单、库存台账、装配历史与页面编排。
