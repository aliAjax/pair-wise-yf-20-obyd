# 烟花弹体装配工位台（hxyfront-62008）

面向烟花弹体装配工位的单页工具：预置四条工位、八只弹壳和四种引信，支持按批装配、减药返工与整批退回。

## 业务规则

- 弹壳台账记录每只弹壳的**口径、壳高与剩余可灌药量**（容量 − 已灌）。
- 装配批次选择：工位、本批弹壳、灌药克数（每只相同）、引信、静电接地确认。
- 出现以下任一情况，**整批退回**，原工位与物料完全不动（仅追加一条退回记录）：
  - 静电接地未确认；
  - 灌药克数超过任一弹壳剩余可灌药量；
  - 引信长度不足任一弹壳壳高的一半；
  - 未选弹壳、引信库存不足、克数非法等基本校验失败。
- 返工只能**减药**（新药重必须小于当前药重）并**重新确认接地**；引信与工位不变。
- 历史装配与返工**只追加、不修改**。

## 文件划分（三个业务文件）

- `src/stationMap.tsx` —— 工位图：A/B 两区四条工位与在台弹壳。
- `src/inventory.tsx` —— 库存：弹壳台账与引信库存。
- `src/App.tsx` —— 装配页面：批次表单、整批校验提交、返工与历史台账。
- 辅助：`src/types.ts`（类型）、`src/data.ts`（预置数据）、`src/store.ts`（reducer + localStorage）。

## 数据存储

数据只保存在本机浏览器 `localStorage`，无后端、无网络请求、无新增依赖。点击页面上的「恢复预置数据」可清空并重置。
